# Live Inspector

Open **Live Inspector** and edit speed, visibility, mode, tint, or position. Health intentionally remains read-only. For remote testing, host this project through Link, join from a trusted tester, and select that peer in the inspector. Edits use compare-and-set; pause before changing continuously moving fields.

Run with `kairo run examples/live-inspector` from the repository root, or create the corresponding starter in Kairo.
