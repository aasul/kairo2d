# Relay Dusk

A complete top-down survival mission made with Kairo's public Lua APIs. Charge three
relays while fighting hunters, ranged sentries, tanks and fast motes. Each relay
offers one of three upgrades. Defeat the Warden, then reach the extraction gate.
The game keeps a best score, clear count and fastest clear in its per-game save.

## Play

From the repository root:

```powershell
target/debug/kairo.exe run examples/relay-dusk --no-watch
```

| Action | Keyboard and mouse | Controller |
| --- | --- | --- |
| Move | WASD or arrows | Left stick |
| Aim | Mouse | Right stick |
| Fire | Left click or Space | Right shoulder |
| Dash | Shift | B |
| Pause | Escape | Start |
| Choose upgrade | 1, 2, 3 | X, A, Y |

The player and arena walls use the native Rapier physics API. Enemy AI, projectiles,
damage and pickup rules live in Lua. The game also uses the scene stack, input
actions, native particles, Kira sound buses, camera transforms, sprites, and scoped
saves. The pixel art and synthesized audio are original assets generated by
`make_assets.py` and covered by the repository MIT license. They are included in
the project, so Python is not needed to play.

Audio is optional. The game runs without an output device. Controller input,
physical audio output and visible GPU rendering require testing on the player's
machine; headless validation alone cannot establish those results.
