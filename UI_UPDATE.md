# Feature UI retained in 3.4

This is a full 3.4 repository, not the old 3.3 overlay patch. It retains the visible
feature bar and adds workflow tools. Extract into a new directory and preserve local
projects/source changes before comparing files. Rebuild both programs; old binary
preferences may need resetting to automatic runtime detection.

See [editor guide](docs/editor.md), [feature access](docs/feature-ui.md) and
[VALIDATION.md](VALIDATION.md). No prebuilt executable is included.
