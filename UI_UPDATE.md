# Feature UI retained in 3.4

Version 3.4 keeps the feature bar and adds more project tools. If you are upgrading,
extract the source into a new folder and keep your existing projects and local edits.
Rebuild both the editor and runtime. If Kairo still opens an older runtime, select
automatic runtime detection in Preferences.

See the [editor guide](docs/editor.md), [feature overview](docs/feature-ui.md), and
[VALIDATION.md](VALIDATION.md). This source release does not include prebuilt
executables.
